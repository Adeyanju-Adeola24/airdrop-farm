# Airdrop Farm

An experimental JavaScript project for exploring automated workflows around blockchain/airdrop activities.

## Project Structure
The repository contains chain-specific modules, configuration, dashboard code and reusable JavaScript templates.

## Tech Stack
- JavaScript
- Node.js
- Blockchain/Web3 tooling

## Getting Started
Install the project's dependencies and review `config.js` and the available scripts before running anything.

```bash
npm install
```

Never commit private keys, seed phrases or other secrets.

## Safety
Use only with wallets, contracts and networks you own or are explicitly authorized to interact with. Review transactions before signing and test on a safe development network when possible.
